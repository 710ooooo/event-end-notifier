Event End Notifier

Google カレンダーの予定が終わる少し前と、終了時刻ちょうどにデスクトップ通知を出す Chrome 拡張機能です。会議の延長や、次の予定への遅れを防ぎます。

主な機能

  • 予定の終了 N 分前（既定 5 分）と終了時刻に通知
  • 通知音のオン・オフ、通知を閉じるまで表示し続ける設定
  • 通知の対象にするカレンダーの選択
  • 不参加と回答した予定や、会議リンクのない予定の除外

Google アカウントのデータについて

カレンダーの一覧と、これから 24 時間以内の予定を読み取るだけです。予定の作成・変更・削除はしません。取得したデータはお使いのブラウザの中にだけ保存し、開発者を含む第三者のサーバーには送りません。詳しくはプライバシーポリシーをご覧ください。

English

Event End Notifier is a Chrome extension that shows a desktop notification shortly before, and right at, the end of your Google Calendar events, so your meetings don't run over.

It only reads your calendar list and the events in the next 24 hours. It never creates, changes or deletes events. All data stays in your browser and is never sent to the developer or any third party. See the Privacy Policy.
